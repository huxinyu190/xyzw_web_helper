# 金鱼活动目标规划 & 图鉴微星

## 功能入口

游戏功能页（`src/components/GameStatus.vue`）底部 Tab 新增「金鱼活动」（位于「切磋」之后）。

- 顶部大卡片：与身份牌同宽（`grid-column: 1 / -1`），含节日选择、目标档位选择、总览、黑市采购设置与今日清单。
- 下方 5 张资源卡：招募令 / 宝箱积分 / 黄金鱼竿 / 金砖 / 盐罐，与「日常」卡片同宽（同一 CSS Grid 单元格）。
- 身份牌资源列表最后新增「图鉴微星」（`src/components/Common/IdentityCard.vue`）。

## 数据口径

### 活动机制（端午 / 中秋 / 元旦 同款）

消耗 5 类资源完成悬赏任务，得到「任务道具」（手套/粽子/月饼），开道具获得「金色道具」，
集齐 **250 个金色道具兑换 1 条 5 星金鱼**。

- 开道具：25% 出金色道具，**5 次保底**
- 单次首中次数 `T` 的分布：`P(T=t)=0.75^(t-1)*0.25 (t<5)`，`P(T=5)=0.75^4`
- 期望 3.0508 次/金色道具 → 250 个期望 **762.7** 个任务道具
- 分位数（精确 DP）：5% = 721，50% = 763，95% = 804，99% = 821

| 资源 | 满档消耗 | 满档道具 |

| 招募令 | 4000 | 400 |
| 宝箱积分 | 100000 | 200 |
| 黄金鱼竿 | 1750 | 280 |

### 图鉴档位 → 需囤目标（社区口径）

图鉴微星越高，图鉴奖励（升星 → 微星 → 每 50 点一次奖励）剩余越少，
能白拿的一次性资源越少，自己需要囤的就越多。社区给出三档入场目标：

| 图鉴微星 | 招募令 | 黄金鱼竿 | 宝箱 | 金砖 |
| --- | --- | --- | --- | --- |
| < 2000 | 2500 | 600~700 | 8.5 轮 | 18 万 |
| 2000~3000 | 2800 | 700 | 9 轮 | 20 万 |
| > 3000 | 3300 | 750+ | 10 轮 | 25 万 |

换算与推导：

- **宝箱轮次**：1 轮 ≈ 3400 库存积分（8000 分消耗，开箱返还后；社区实测 3340~3440），
  8.5 / 9 / 10 轮 ≈ 28,900 / 30,600 / 34,000 积分。
- **招募令**：任务 4000，减档位目标 = 1500 / 1200 / 700 的活动内可获得；
  扣掉开道具 + 钓鱼约 720 后，图鉴贡献约 780 / 480 / 0，正好对应微星越低返还得越多。
- **金砖**：任务 50 万，减档位目标 = 32 / 30 / 25 万的活动内可获得；
  扣掉常规返还约 21.4 万后，图鉴贡献约 10.6 / 8.6 / 3.6 万。
- **黄金鱼竿**：任务 1600，减档位目标 ≈ 900~1000，扣钓鱼返还 178 + 活动期直购 600 后，
  图鉴贡献约 100~170。

实现：`BOOK_TIER_TARGETS`（`constants.js`）保存三档数值，`getBookTier()` 按微星取档；
未识别微星时按 > 3000 保守计算；也可在「采购设置 → 图鉴档位」手动选 auto/low/mid/high。
鱼竿/金砖会随档位方案微调：鱼竿 `+ (preset.rod - 1600)`，金砖 `+ (preset.gold - 500000)`。

> 宝箱开箱返还比例 `CHEST_STOCK_RATIO = 0.5` 仅用于卡片明细展示；
> 活动期直购鱼竿 `ROD_EVENT_DIRECT = 600`（约 38.8 万金砖）计入金砖消耗任务。

## 图鉴微星识别

`src/utils/roleBook.js` 按优先级解析：

1. 手动覆盖值（`localStorage: goldfish:bookStar`，身份牌与规划共用）
2. `role.bookPoint / bookStar / microStar / …`
3. `role.statistics / statisticsTime['book:point' / 'book:star']`
4. `role.book / bookInfo / heroBook / handbook / collection` 内的 point/star/score/value
5. 深度扫描（路径含 book/handbook/collection + point/star/score/micro）
6. 兜底：图鉴收录计数（bookCount / collectionCount）

不再使用“已拥有武将数”。自动解析失败时，可在「采购设置 → 图鉴微星」直接填游戏内数值；
开发环境会在控制台打印 `role` 顶层键与候选字段，便于定位协议字段。

图鉴活动内返还：`(1 − 微星 / 4600) × 120` 招募令（低微星账号升星空间大，返还得更多）。

## 进度条与返还

- 资源卡进度条 = **现有 / 需囤**，不含活动内返还；
- 卡片标题下方显示「任务 X · 活动内可拿 Y」，再下面是明细（开箱循环 / 钓鱼 / 直购 / 图鉴）；
- 大卡片进度条 = **现有折算道具 / 目标道具**，同样不含返还；
- 「预计可得」= 现有 + 活动内可获得。

## 黑市采购规划

`src/utils/goldFish/market.js` + 大卡片里的「黑市采购计划」。

- 商品（价格 / 兑换 / 每日限购）：
  | 商品 | 价格 | 产出 | 日限 |
  | --- | --- | --- | --- |
  | 黑市黄金鱼竿 | 400 砖 | 1 竿 | 10 |
  | 黑市青铜宝箱 | 100 砖 | 10 分 | 4 |
  | 黑市铂金宝箱 | 500 砖 | 50 分 | 2 |
  | 黑市招募令 | 250 砖 | 1 个 | 10 |
  | 金砖直购鱼竿 | 646 砖 | 1 竿 | 不限（默认不参与活动期覆盖） |
  | 黑市黄金宝箱 | 300 砖 | 20 分 | 2 |
- 优先级：用户可勾选 / 上下调整，默认 鱼竿 → 青铜 → 铂金 → 招募 → 直购 → 黄金。
- 分配逻辑：
  1. 缺口来自 `plan.rows[].gap`（目标 − 现有 − 返还 − 图鉴折算）；
  2. 活动 7 天内黑市能买到的量优先留到活动期买（可同时完成金砖消耗任务）；
  3. 活动期买不完的部分才安排到活动前，按每日限购与剩余天数摊成「今日清单」；
  4. 预算 = 现有金砖 + 每日金砖收入 ×（距活动天数 + 7）；
  5. 今日花费 = 「今日清单」合计，且不超过 `每日收入 + 现有金砖 / 剩余天数`。
- 输出：今日清单与花费、活动前/活动期花费、采购后道具与成功率、未补齐项、金砖任务差额。
